# Nuido Flow AI Option Model

AI 動態配置管理模組 - 支援多供應商 AI 模型動態配置

## 🎯 **專案概述**

此模組為 Nuido Flow AI 系統提供動態 AI 供應商和模型配置管理功能，支援 OpenAI 相容的 API 格式，實現無縫的多供應商整合。

## 📁 **目錄結構**

```
nuido_flow_ai_option_model/
├── __init__.py                     # 模組初始化
├── __manifest__.py                 # 模組配置文件
├── README.md                       # 專案說明文檔
├── requirements.md                 # 需求規劃文檔
├── models/                         # 資料模型
│   ├── __init__.py
│   ├── nuido_ai_provider.py       # AI 供應商模型
│   ├── nuido_ai_model.py          # AI 模型配置模型
│   └── api_service.py             # 配置服務 API
└── security/                      # 安全權限配置
    └── ir.model.access.csv        # 模型訪問權限
```

## 🏗️ **核心架構**

### 資料模型

1. **`nuido.ai.provider`** - AI 供應商管理
   - 供應商基本資訊 (名稱、描述、API URL)
   - API 認證配置 (API Key、API 類型)
   - 連接狀態管理 (連接測試、錯誤處理)
   - 模型探測和更新

2. **`nuido.ai.model`** - AI 模型配置
   - 模型基本資訊 (名稱、模型 ID、類型)
   - 參數配置 (溫度、Top P、最大 Token)
   - 供應商關聯和預設設定
   - API 配置生成

3. **`nuido.ai.config.service`** - 配置服務
   - 動態供應商和模型查詢
   - 配置整合和驗證
   - 預設模型管理

## ✨ **核心功能**

### 供應商管理
- ✅ 多供應商配置 (OpenAI, Qwen, Gemma 等)
- ✅ API 連接測試和狀態監控
- ✅ 自動模型探測和同步
- ✅ 錯誤處理和診斷

### 模型配置
- ✅ 模型參數管理 (溫度、Top P、最大 Token)
- ✅ 模型類型分類 (對話、文本生成、嵌入等)
- ✅ 預設模型設定
- ✅ 參數驗證和約束

### 動態服務
- ✅ 運行時配置查詢
- ✅ 供應商和模型列表 API
- ✅ 配置整合服務
- ✅ 預設值管理

## 🔧 **技術特點**

- **非侵入式設計**: 不修改現有 nuido_flow_ai 代碼
- **OpenAI 相容**: 支援所有 OpenAI API 相容的供應商
- **動態配置**: 運行時動態載入配置
- **錯誤恢復**: 完善的錯誤處理和狀態管理
- **安全權限**: 細粒度的訪問控制
